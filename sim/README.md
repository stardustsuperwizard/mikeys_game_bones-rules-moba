# sim/ — Python Balance Harness

The Python balance harness for Mikey's Game Bones MOBA Rules. This package
contains formula implementations, ability loading, and balance testing
infrastructure for the portable combat rules engine.

## §65 Division of Responsibility

Per §65 of the [ruleset](../docs/pulp_moba_rpg_ruleset.md), Python owns exploratory and statistical balance work:

- **Formulas live only in Python** (`sim/formulas.py`). This is the single source of truth for damage calculation, cooldown reduction, and critical strike mechanics.
- **Ability data is read from JSON**, produced by the Godot-side export tool. The harness never modifies `rules/data/generated/`.
- **GDScript/Godot is responsible for conformance**. A fixed set of test scenarios validate that both implementations compute the same results within tolerance.

This split ensures:

1. **Fast statistical work**: Python's pytest, Hypothesis, and numpy ecosystem enables Monte Carlo simulation across thousands of builds without waiting for Godot.
2. **Shared data, not shared code**: Ability stats and formula inputs live in JSON schema, not duplicated across languages.
3. **Clear ownership**: Changes to combat math must be reflected in both Python and GDScript, but the Python side is the reference.

## Running Tests

### Install dependencies

```bash
pip install -e ".[dev]"
```

### Run all tests

```bash
pytest sim/
```

### Run only fast tests (excluding deep markers)

```bash
pytest sim/ -m "not deep"
```

### Run only deep tests

```bash
pytest sim/ -m deep
```

## Export Dependency

The harness requires `rules/data/generated/abilities.json` to exist and be up-to-date. This is regenerated by `conftest.py` on test startup:

- If `rules/data/generated/` is missing or older than any `.tres` file in `rules/`, Godot is invoked to export.
- If Godot is unavailable, tests fail loudly with a clear error message naming the binary and GODOT_BIN variable.
- Set `GODOT_BIN` to specify a custom Godot binary path if not on PATH.
