# Weapon Definitions

Authored as `.tres` Godot Resource files in the Godot inspector.
Each weapon resource extends `MobaWeapon` and defines basic attack behavior:
damage, damage type, attack speed, range, wind-up, recovery, and optional projectile speed.

## Available Weapons

- **longsword.tres** — Melee weapon with 50 damage, 2.0m range, 1.0 attack speed.
